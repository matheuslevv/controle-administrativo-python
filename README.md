# Controle Administrativo em Python

Projeto simples desenvolvido em Python com o objetivo de praticar lógica de programação.

## Funcionalidades
- Cadastro de itens
- Listagem de itens cadastrados
- Menu interativo no terminal

## Tecnologias utilizadas
- Python 3

## Objetivo
Projeto educacional voltado para aprendizado e demonstração de conhecimentos básicos em Python, para estudantes em busca de estágio na área de TI.
